# 🍋 Lemon Party (Neuron Arena & Party Games)

> Автономная интерактивная игровая платформа для совместного принятия решений, командных игр, рулетки желаний и турниров нейронных персонажей в экосистеме **The Lemon Team**.

**Repository:** `git@github.com:The-Lemon-Team/lemon-party.git`

---

## 🎮 Основные Режимы и Возможности

1. **🍕 Комнаты & Мультирум (Party Realtime Hub)**:
   - Живые игровые комнаты в реальном времени с поддержкой переключения контекста.
   - Лента живых событий (пользователь вошел, отдан голос, разыграна карта, зафиксирована комбинация).
   - Фильтры комнат по тегам и статусам (`LIVE`, `VOTING`, `SCHEDULED`, `WRAPPED_UP`).

2. **🎡 Рулетка Желаний & Колесо Фортуны (Party Roulette)**:
   - Интерактивное физическое колесо фортуны с анимацией вращения и аудиовизуальными эффектами.
   - Секторы желаний, привязанные к активным картам и персонажам.
   - Интеллектуальный выбор совместных активностей.

3. **⚡ Арена Нейронов & Игровое Поле (Neuron Arena)**:
   - **Versus View**: Схватки нейронных персонажей, оценка парадоксов, генерация исходов раундов.
   - **Combine View**: Матрица объединения идей и желаний, синхронизация таймслотов и генерация синергетических активностей.

4. **👥 Герои & Карточки Персонажей (Neuron Heroes)**:
   - Каталог персонажей (30+ уникальных архетипов с векторными аватарами).
   - Фильтрация по категориям: `LEAD`, `ANALYST`, `CREATIVE`, `CRITIC`, `CHILL`.
   - Модальное окно создания и редактирования персонажей с выбором иконки (`IconPickerComponent`).

5. **🃏 Колода Желаний (Party Cards)**:
   - Интерактивная колода карт желаний с аналитикой напряженности и категорий.
   - Полноэкранный детальный просмотр и добавление новых карт.

6. **🌐 Хроно-Облако (Party Cloud)**:
   - Интерактивное визуальное облако комнат и активностей с таймлайном и временными горизонтами.
   - Синхронизация между комнатами, карточками и расписанием.

7. **📜 Летопись & AI Датасет (Party Chronicle)**:
   - Журнал голосовых сообщений и тренировочных выборок для нейросетевых моделей.

---

## 🛠️ Технологический Стек

- **Angular 18** (Standalone Components, Signals, Router, Control Flow `@if` / `@for`)
- **Tailwind CSS** (Дизайн-система "Lemon Seasons", Atom One Light / Dark темы)
- **Material Symbols Rounded** (Локальные шрифты без внешних CDN)
- **Web Audio API** (Звуковой движок `PartySoundService` для рулетки, побед и кликов)
- **RxJS** (Реактивные потоки и шина данных)

## 🚀 Запуск и Разработка

### Установка зависимостей
```bash
npm install
```

### Запуск dev-сервера
```bash
npm start
# или
ng serve --host 0.0.0.0 --port 4201
```
Приложение откроется по адресу `http://localhost:4200` (или выбранному порту).

### Запуск тестов
```bash
npm test
```

### Сборка production
```bash
npm run build
```
